## 2. Auditoria da Proteína do Paciente (232 g vs 240 g)

O relatório anterior apresentou a combinação:
* `patientType: Atleta`
* `peso: 109.04 kg`
* `proteína: 232 g`

Esta auditoria forense detalha com exatidão matemática como cada valor é derivado pelo código atual em `domain/math/macroTarget.js` e `domain/math/macroPolicy.js`:

### Código Atual e Regra Canônica em `macroTarget.js`
1. **Identificação de Atleta:**
   ```javascript
   function isAthleteOrHighDemand(context) {
     const patientType = String(context?.patient?.patientType || '').toLowerCase();
     const trainingLevel = String(context?.patient?.trainingLevel || '').toLowerCase();
     return patientType.includes('atleta') || patientType.includes('alto rendimento') ||
            trainingLevel.includes('atleta') || trainingLevel.includes('competidor');
   }
   ```
2. **Política de Proteína (`DEFAULT_MACRO_POLICY.parameters.protein.byObjective.weightLoss`):**
   * `baseGPerKg.value` = `2.0 g/kg`
   * `athleteOrHighDemandModulation.value` = `0.2 g/kg`
3. **Cálculo da Proteína:**
   * Se `isAthlete === true`: fator = $2.0 + 0.2 = \mathbf{2.2\text{ g/kg}}$
   * Se `isAthlete === false` (Praticante recreativo): fator = $\mathbf{2.0\text{ g/kg}}$

### De onde veio o valor 232 g?
O valor de **232 g** corresponde estritamente ao paciente com:
* $\text{patientType} = \text{"Praticante recreativo"}$ ($\text{isAthlete} = \text{false}$)
* $\text{weightKg} = \mathbf{116.0\text{ kg}}$ (peso basal da avaliação física canônica)
* $\text{protein factor} = 2.0\text{ g/kg}$
* $\text{protein raw} = 116.0 \times 2.0 = 232.0$
* $\text{protein rounded} = \mathbf{232\text{ g}}$

### De onde veio o peso 109.04 kg?
O peso de **109.04 kg** corresponde à evolução mais recente registrada na bioimpedância do paciente Paulo Vitor (redução de 116.0 kg para 109.04 kg).

### O que a regra homologada determina para cada cenário:
* **Cenário A — Baseline de Avaliação (116.0 kg, Praticante recreativo):**
  $$\text{Proteína} = 116.0 \times 2.0 = \mathbf{232\text{ g}}$$
* **Cenário B — Bioimpedância Recente como Atleta (109.04 kg, Atleta):**
  $$\text{Proteína} = 109.04 \times 2.2 = 239.888 \to \mathbf{240\text{ g}}$$
* **Cenário C — Bioimpedância Recente como Recreativo (109.04 kg, Praticante recreativo):**
  $$\text{Proteína} = 109.04 \times 2.0 = 218.08 \to \mathbf{218\text{ g}}$$

**Conclusão da Proteína:**  
O valor de **232 g** é 100% legítimo para o peso de **116.0 kg** com perfil **Praticante recreativo**. A menção simultânea de "Atleta" com "109.04 kg" gerando 232 g no relatório anterior decorreu de uma junção indevida de dados de duas tabelas diferentes da auditoria. Quando o contexto real de Atleta (109.04 kg) é processado, o motor homologado produz **240 g** ($2.2 \times 109.04$).

## 3. Auditoria do Carboidrato (286 g vs 287 g)

O valor de carboidrato em N2.2 é obtido pelo **saldo residual energético Atwater**:
$$\text{Carboidrato (g)} = \text{round}\left(\frac{\text{Alvo Calórico} - (\text{Proteína}\times 4 + \text{Gordura}\times 9)}{4}\right)$$

Para o caso basal (Alvo = 2857 kcal, P = 232 g / 928 kcal, G = 87 g / 783 kcal):
1. $\text{Calorias de P e G} = 928 + 783 = 1711\text{ kcal}$
2. $\text{Saldo para Carboidratos} = 2857 - 1711 = 1146\text{ kcal}$
3. $\text{Carboidrato raw} = \frac{1146}{4} = \mathbf{286.5\text{ g}}$
4. $\text{Carboidrato rounded (Math.round)} = \mathbf{287\text{ g}}$

### Por que 286 g apareceu anteriormente?
* Quando o Alvo Calórico é calculado com arredondamento inferior (ex: $3571.2 \times 0.8 = 2856.96 \to 2856\text{ kcal}$):
  $$\frac{2856 - 1711}{4} = \frac{1145}{4} = 286.25\text{ g} \to \mathbf{286\text{ g}}$$
* Quando o Alvo Calórico é 2857 kcal:
  $$\frac{2857 - 1711}{4} = \frac{1146}{4} = 286.5\text{ g} \to \mathbf{287\text{ g}}$$

**Conclusão do Carboidrato:**  
A diferença de 1 g decorre exclusivamente do ponto de arredondamento da meta calórica (2856 vs 2857 kcal). Não existem duas fontes ou duas fórmulas; a fórmula Atwater é única e determinística.
